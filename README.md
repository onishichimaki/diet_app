# Habi

**今日を、ちょっといい日に。**

Habi is a calm, mobile-first personal health app for tracking meals, calories,
macronutrients, weight, steps, exercise, and sleep in one place.

## Included

- Today dashboard with calorie and PFC progress
- Meal logging by breakfast, lunch, dinner, and snack
- Weight, walking, exercise, and sleep records
- Daily goals and notification preferences
- Daily, weekly, and monthly report views
- First-use sample data
- Durable D1 storage
- Responsive iPhone-friendly UI and installable web-app metadata

## Start

```powershell
npm install
npm run dev
```

Open `http://localhost:3000`.

## Quality checks

```powershell
npm test
npm run lint
npm run build
```
